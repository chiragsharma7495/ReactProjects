# Hangman Game

A small Hangman game built with React, React Router, Vite, and Tailwind CSS.

## Features

- Enter a word on the start screen.
- Navigate to the game using React Router navigation state.
- Reveal correctly guessed letters in the masked word.
- Disable letters after they are selected.
- Mark guesses as correct or incorrect with button colors.
- Display progressive Hangman artwork for incorrect guesses.
- Redirect the root URL to the start screen.

## Running locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, then enter a word and submit it to start.

## Validation

```bash
npm run lint
npm run build
```
