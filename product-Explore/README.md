# Product Explorer

A responsive React and Tailwind CSS product browser powered by the DummyJSON products API.

## Features

- Search products by name
- Filter products by category
- Sort products by price
- Responsive product cards with images and ratings
- Loading skeletons, empty results, and retry states

## Run locally

```bash
npm install
npm run dev
```

To verify the project:

```bash
npm run lint
npm run build
```
